Vibe — A Simple Social Media App

Vibe is a lightweight social media web application designed to help people connect, share posts, and communicate.

Features

- User profiles
- Create and view posts
- Like and comment on posts
- Follow other users
- Search for users
- Direct messaging

Technology

- HTML, CSS and JavaScript
- Supabase for authentication and database
- Cloudflare Pages for deployment
- GitHub for source code management

Getting Started

1. Clone or download this repository.
2. Configure your Supabase project.
3. Set up the database using "supabase.sql".
4. Configure the app with your Supabase project details.
5. Deploy the app using Cloudflare Pages.
